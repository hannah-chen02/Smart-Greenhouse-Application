# Smart-Greenhouse-Application
---------------README--------------------
AUTHOR: Hannah Chen

DATE: 19/05/2026

PROGRAM: GreenhouseMenu.java

DEPENDACIES: SensorReading.java, Timestamp.java

OVERVIEW: The Smart Greenhouse Monitoring System is a Java program that is designed to manage and analyse greenhouse sensor readings. The program is shown to the user as a menu, which the user can navigate. It loads a CSV file upon startup to access readings, stores sensor date in arrays, allows user to delete and add readings, and computes calculations to generate statistics for the greenhouse.
